# Ren-ren Linas — Personal Portfolio



A one-page personal portfolio built with semantic HTML and responsive CSS. The page uses the profile information and portrait supplied by Ren-ren, with a clear white-and-blue visual style.



## Project structure



- `index.html` — portfolio content and page structure
- 
- `styles/style.css` — responsive layout, colors, typography, and component styling
- 
- `assets/ren-ren-linas.png` — supplied profile photograph
- 
- `assets/favicon.svg` — RL monogram favicon
- 


## Publish with GitHub Pages



This folder is the root of the `linas-project-1` repository. In the repository's Settings → Pages, choose deployment from the `main` branch and `/ (root)`, then save.
